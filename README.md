# Эмулятор командной оболочки (вариант 23), этап 3

## 1. Общее описание

Консольный эмулятор оболочки UNIX на Python 3 (только стандартная
библиотека). Этап 3: VFS загружается из ZIP-архива и целиком
хранится в памяти.

Структура проекта:

    src/errors.py       исключения ShellError и VFSError
    src/line_parser.py  разбор строки, раскрытие $ПЕРЕМЕННЫХ
    src/vfs.py          VFS: дерево в памяти, загрузка из ZIP
    src/commands.py     ls, cd (заглушки), vfs-init, exit
    src/core.py         класс Shell: execute, REPL, стартовый скрипт
    src/shell.py        точка входа и параметры командной строки
    tests/              автотесты (unittest)
    examples/           стартовые скрипты эмулятора (*.emu)
    scripts/            скрипты реальной ОС для проверки (*.sh)

## 2. Функции и настройки

### Параметры командной строки

| Параметр        | Что делает                                   |
|-----------------|----------------------------------------------|
| `--vfs PATH`    | ZIP-архив с VFS (без него: VFS по умолчанию) |
| `--script PATH` | стартовый скрипт с командами эмулятора       |

При запуске печатаются все заданные параметры (`[debug] ...`).

### Стартовый скрипт

Команды выполняются по очереди, на экране видны и ввод, и вывод.
Ошибочные строки пропускаются, сообщение содержит имя файла и номер
строки. Строки с `#` выводятся как комментарии. Если в скрипте нет
`exit`, после него откроется REPL.

### Приглашение и команды

Приглашение содержит имя VFS. Переменные окружения реальной ОС раскрываются (`ls $HOME`).

| Команда         | Описание                                    |
|-----------------|---------------------------------------------|
| `ls [арг...]`   | заглушка: печатает имя и аргументы          |
| `cd [арг]`      | заглушка: печатает имя и аргумент           |
| `vfs-init`      | заменить VFS на встроенную; ZIP на диске очищается |
| `exit`          | выход                                       |

Ошибки: неизвестная команда, неверные аргументы.

`vfs-init` очищает физическое представление VFS: в ZIP-файл
записывается VFS по умолчанию. Остальные операции работают
только в памяти.

## 3. Сборка и тесты

Сборки нет, нужен только `python3`.

    sh run.sh                         запуск эмулятора
    sh scripts/run_tests.sh           автотесты
    sh scripts/test_stage2_basic.sh   параметры: основное
    sh scripts/test_stage2_paths.sh   параметры: пути и порядок
    sh scripts/test_stage2_errors.sh  параметры: ошибки
    sh scripts/test_stage3_script.sh  разные VFS + скрипт
    sh scripts/test_stage3_stdin.sh   разные VFS + stdin
    sh scripts/test_stage3_errors.sh  загрузка VFS: ошибки

Тестовые ZIP создаёт `scripts/make_vfs.py` во временной папке.

## 4. Примеры использования

    $ python3 scripts/make_vfs.py /tmp/vfs
    $ sh run.sh --vfs /tmp/vfs/deep.zip
    deep:/$ vfs-init
    default:/$
